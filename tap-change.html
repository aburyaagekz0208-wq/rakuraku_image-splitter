処理仕様 / Processing

本体画像 / Base Imageは、画像の外周とつながっている完全白 RGB(255,255,255) の背景だけを自動で透明化し、その後、1pxごとの市松模様で透明/不透明を交互に適用します。左上ピクセルは常に不透明スタートです。白寄せ処理は行いません。

前面レイヤーは読み込んだ透明情報を保持し、透明でない部分を完全不透明にして上に重ねます。白透過処理は行いません。 / The front layer keeps its transparency and any non-transparent pixels are made fully opaque when composited on top. No white-to-transparent processing is applied.

不透明スタンプ / Opaque Stamp

手書き風の不透明スタンプ / Opaque Stampを画像の上に追加できます。追加後は、プレビュー上でドラッグして移動できます。

※ プレビュー上でドラッグ移動できます / You can drag it on the preview

保存 / Save

投稿用PNGは、255色・GIMP相当のPNG-8 indexedとして保存 / Saveします。通常PNG保存 / Save Normal PNG / Saveは比較・確認用です。
