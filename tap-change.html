タップチェンジ画像作成君

本体画像 / Base Imageを1px市松模様で透明化し、前面レイヤーやTapスタンプを重ねて、X投稿向けPNG-8 indexed画像を作成します。

入力

本体画像から、前面レイヤーとして残したい部分を青マスクで選択します。作業は右側の大きな「保存 / Saveされる最終画像」上で行います。青い範囲は保存画像には焼き込まれず、前面レイヤーとしてだけ反映されます。

編集中は右側キャンバスでマスク編集します。ホイール / ピンチで拡大縮小できます。確定するとスタンプ位置調整に戻ります。

キャンバス

幅または高さを変更すると、元画像の縦横比を保ってもう片方を自動計算します。

リサイズ処理は常に最高品質・Lanczos3相当で実行し、保存形式はPNG固定です。画質方式や保存形式の選択肢は表示しません。

不透明スタンプ / Opaque Stamp

手書き風の不透明スタンプ / Opaque Stampを画像の上に追加できます。追加後は、プレビュー上でドラッグして移動できます。

※ プレビュー上でドラッグ移動できます / You can drag it on the preview

保存 / Save

投稿用PNGは、255色・GIMP相当のPNG-8 indexedとして保存 / Saveします。通常PNG保存 / Save Normal PNG / Saveは比較・確認用です。

ガイド / Guide

処理仕様 / Processing Specification
  • 本体画像は、背景と白地の抜けを考慮しつつ、1px市松模様の透明化処理を使ってタイムライン向け画像を生成します。
  • 前面レイヤーは、別画像をアップロードする方法と、このツール内でマスク作成して切り抜く方法の両方に対応しています。
  • この場で前面レイヤーを作成する場合、青くマスクした部分だけが前面レイヤーとして扱われ、保存画像に青い表示は焼き込まれません。
  • Tapスタンプは、文字・色・縁取り・回転・位置・サイズを個別に保持したまま複数配置できます。
  • 保存時は、X投稿用途を想定した PNG-8 indexed 形式で出力します。透明部分を含みつつ、色数は減色されます。
  • 保存サイズは 元画像サイズ / 1/2 / 1/3 / カスタムサイズ から選択できます。
  • 前面レイヤー作成モードでは、右側の大きなプレビュー上で直接マスク編集し、確定後にスタンプ位置調整へ戻れます。
このツールの具体的な操作方法 / How to Use This Tool
  1. 本体画像を読み込みます。
  2. 前面レイヤーを「アップロード」または「この場で作成」から選びます。
  3. 「この場で作成」を使う場合は、補助ブラシ / 手動 / Pan を切り替えながら、右側プレビュー上で残したい部分を青マスクで指定します。
  4. 補助ブラシは、ブラシ中心付近の色に近い部分だけを追加・削除できます。境界の細かい修正は手動ブラシが向いています。
  5. 表示を動かしたい時は、マウスホイール中央ボタンのドラッグ、または Pan、Space + ドラッグ を使います。ホイール回転で拡大縮小できます。
  6. 前面レイヤーの編集が終わったら 前面レイヤー確定 / Confirm を押します。あとから直したい場合は 再編集 / Re-edit で戻れます。
  7. Tapスタンプを追加し、文字内容・色・縁取り・位置・サイズ・回転を調整します。必要ならコピーして量産できます。
  8. 右側の「保存 / Saveされる最終画像」で仕上がりを確認し、最後に 保存 / Save で出力します。
